# Mystic Coders Homebrew tap

```sh
brew install --cask mysticcoders/tap/volant
```

[Volant](https://usevolant.com) is a free, open-source, sandboxed launcher for macOS 15 or later on Apple silicon. It updates itself through Sparkle; `brew upgrade --cask` also works. Source: [mysticcoders/volant](https://github.com/mysticcoders/volant).

# Mystic Coders Homebrew tap

Homebrew casks and formulae for apps and tools from [Mystic Coders](https://github.com/mysticcoders).

```sh
brew tap mysticcoders/tap
```

| Cask | Install | About |

| [Volant](https://usevolant.com) | `brew install --cask mysticcoders/tap/volant` | A free, open-source, sandboxed launcher for macOS 15 or later on Apple silicon.
